# Technical Reference

These documents describe the current runtime contract and operator-facing
system design. Product behavior summaries live in `../product/`; executable
activation procedures live in `../runbooks/`.

- `ARCHITECTURE.md`: service shape and ownership boundaries.
- `API_SPEC.md`: HTTP endpoint and access contract.
- `DATABASE_SCHEMA.md`: Supabase tables, RPCs and migrations.
- `DATA_SOURCES.md`: upstream catalog and OTA dependencies.
- `DEPLOYMENT.md`: runtime configuration and deployment gates.
- `IMPLEMENTATION_PLAN.md`: delivery and activation sequence.
- `RESOLVER.md`: proof-gated URL resolver.
- `SCHEDULER.md`: scan orchestration.
- `SECURITY_NOTES.md`: security controls and secret handling.
- `TELEGRAM_BOT.md`: notification/command surface.
